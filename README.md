# Georgian-for-Pebble
Georgian language pack for Pebble smartwatch, generated from Noto Sans Georgian font under SIL OFL.

source font from Google: https://fonts.google.com/noto/specimen/Noto+Sans+Georgian?preview.script=Geor

installation: place georgian.pbl on the same device that uses your Pebble app. Open georgian.pbl with the Pebble app. You may need to install Rebble to the Pebble app by visiting https://boot.rebble.io in the web browser.
